# 页面姓名的后台字体

主卡片姓名（包括后方的姓名预览）和收藏项姓名在字体准备好后使用霞鹜文楷 Medium。其余文字继续使用系统字体。

三个 page-font 分包合起来覆盖 6,763 个 GB2312 汉字，WOFF 数据以 base64 JS 模块打包，版权信息和 SIL OFL 1.1 保留。再生成：`python 脚本/生成页面文楷字体.py <LXGWWenKai-Medium.ttf>`。

不配置分包预加载，不在 onLaunch、session 或首屏数据请求中等待字体。卡片显示两秒后才后台顺序加载，注册到 webview。全部成功才应用字体类，失败继续显示系统字体；当前正在滑动时延迟切换，已经关闭的页面不再更新。

采用 WOFF 格式照顾 iOS 页面字体兼容性。Data URL 依赖支持该能力的微信基础库；不支持时按普通加载失败处理，无弹窗、无空白姓名。分享图继续走本地轮廓绘制，不依赖页面字体是否成功加载。
