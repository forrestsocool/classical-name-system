# 个人中心筛选

## 页面

保留系统导航栏的“个人中心”，删除页面内重复标题、副标题与“寻”标识。沿用首页系统字体、纸白底色（#f7f5ee）、青绿（#216255）、浅色描边与圆角纸卡。依次展示名字用字、名字来源、继续寻名、账户信息；OpenID 保留。

## 筛选约定

- 必须包含：最多两个不同汉字，每个字都必须出现在名字中，不要求位置顺序。
- 避开的字：最多 32 个不同汉字，名字中不能出现其中任意一个字。
- 用字只匹配名字，不包含用户填写的姓氏；两组出现同一个字时提示冲突并保留上次有效设置。
- 来源由数据库 books 的完整目录提供，包含古籍与东亚年号；无库存的来源也列出。默认全开，逐项切换，支持全开、全关。
- 采用禁用来源名单，新加入的来源默认开启。全关确实返回空结果，不自动放宽条件。
- 来源、用字、首页性别与单双字共同筛选。双字必含条件切到单字时提示调整条件。
- 设置按当前用户保存在本机，返回首页立即应用；收藏和曝光去重仍使用微信身份，由服务器维护。

## 接口与缓存

新增受现有网关鉴权保护的 sources.list（仅返回 name、kind）；feed.pull 增加 excluded_sources，并启用原 required、excluded 字段。所有 SQL 参数绑定；过滤在写入曝光之前完成。非空条件参与请求指纹，相同请求编号不能换条件重用；空条件兼容旧版本回执。

首页缓存升级到 v4，兼容读取 v3：六个性别/字数卡池保留未消费卡片，展示时应用当前条件；不同条件独立保存未完成请求，失败重试复用原编号。迟到响应只能进入缓存，不改变当前筛选；收藏/略过按显示卡片 ID 消费。

服务端继续运行单字、双字两个持续入库队列，年号加入正常生产轮转；年号批次的提示词允许按现代人名标准评审年号，仍排除强烈帝王专属联想等不适宜内容，质量门槛不变。无数据库结构迁移，无需清空库存、收藏、曝光记录。

## 验证

真实 PostgreSQL 验证组合筛选、年号、来源全关、去重与回执兼容；页面测试覆盖自动保存、冲突、目录失败重试、缓存过滤、迟到响应和收藏当前卡片。部署顺序为服务器、云函数、客户端，兼容旧客户端。
