# 分享图片素材

背景沿用小程序分享封面，固定朱印由内置 ImageGen 生成。最终提示词：五字“好名书中来”，从上到下单列竖排，朱砂红底、白色手写刻印字，透明背景，克制的印泥磨损纹理。

名字使用 LXGW WenKai Medium v1.522，授权见 OFL.txt。名字、出处和文化标签均来自现有物料，服务端 Pillow 渲染 750×600 JPEG，无需调用图像模型或生成新文案。姓名只取 given_name，不包含发送者姓氏或乳名。

小字使用服务器已有授权字体，环境变量 SHARE_SMALL_FONT 指定路径，默认 `/app/构建产物/运行数据/分享字体/msyh.ttc`。私有字体文件不提交到 Git，不提供字体下载接口；缺失时回退到文楷。PUBLIC 图像地址由 SHARE_IMAGE_BASE_URL 指定，默认 https://name.sensen.li 。

图片地址为 `/share-card/<分享token>.jpg`，每次先核验分享与原文仍可用，再读取内存渲染缓存。失效或撤回的来源返回 404。
