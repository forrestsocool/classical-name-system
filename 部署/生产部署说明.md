# 生产部署

1. 设置长度不少于16个字符的 `起名管理密钥`。
2. 执行 `启动服务.ps1`，SQLite 使用一个工作进程。
3. 使用 Caddy 加载 `Caddyfile`，反向代理到 `127.0.0.1:8000`。
4. 使用 `健康检查.ps1` 检查 `/api/ready`。
5. 使用 `脚本/备份数据库.py` 定期备份数据库。
6. 使用 Prometheus 加载 `部署/prometheus.yml`，抓取 `/metrics`；将 `部署/起名系统告警.yml` 放入 Prometheus 的规则目录。
7. 发布前执行生产配置压测：

   ```powershell
   python 脚本/生产压测.py --地址 http://127.0.0.1:8000 --请求数 30 --并发数 5
   ```

   正式域名部署后，将 `--地址` 改为实际服务地址，并保存命令输出作为发布验收记录。
