# 唐诗、宋词来源

来源为 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的《唐诗三百首》《宋词三百首》选集，实际收录唐诗 366 首、宋词 280 首，并非全唐诗、全宋词。

本目录保存原始 JSON、上游 LICENSE 和来源记录（固定提交、原始哈希、输出哈希）。`古籍全文/唐诗.txt`、`古籍全文/宋词.txt` 使用 OpenCC `t2s` 转换为简体，每首保留作者和题名；宋词使用词牌名。长篇沿用现有 240 字切分，作者与题名不参与取名。

原文默认标为待核验。PostgreSQL 生产器通过既有待核验召回与模型审稿流程筛选名字，不把自动转换当作人工校勘。

增量导入前，先备份生产数据库并停止生产器。在已完成数据库迁移、已配置 `DATABASE_URL` 的运行环境中执行：

```sh
python 脚本/导入诗词来源.py
# 查看演练结果，再应用
python 脚本/导入诗词来源.py --apply
```

默认演练事务回滚；重复应用不会插入重复片段，不会覆盖原有核验或停用状态，也不会重置用户收藏、投递或已生成名字。来源哈希变化时拒绝覆盖，需要另行审查升级。导入成功后恢复生产器；`sources.list` 会自动返回唐诗、宋词，个人中心默认开启，单独关闭某来源会通过原有筛选逻辑生效。

新来源需要生产器积累通过审稿的名字后才能在首页发卡。客户端没有硬编码书目，增加来源无需上传新小程序包。
